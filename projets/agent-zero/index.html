🤖 Agent Zero Assistant IA Autonome

Déploiement d'un agent IA conversationnel autonome avec Docker, Google Gemini et OpenRouter

🐍 Python 🐳 Docker 🤖 Gemini 🌐 OpenRouter 🖥️ Kali Linux 🔧 Supervisor 📦 Flask

📖 Introduction

Agent Zero est un framework d'agent IA autonome qui permet de dialoguer avec des modèles de langage via une interface web. Ce projet consiste à déployer Agent Zero dans un conteneur Docker Kali Linux, configurer l'accès à des modèles IA (Google Gemini et OpenRouter), et tester l'assistant.

🎯 Objectifs

  • Déployer Agent Zero avec Docker sur Kali Linux
  • Configurer l'accès à des modèles IA (Gemini / OpenRouter)
  • Tester et interagir avec l'agent via l'interface web
  • Documenter les difficultés rencontrées et les solutions apportées

🏗️ Architecture du projet

Architecture technique du déploiement Agent Zero

Composants principaux

  • Agent Zero : Framework d'agent IA autonome
  • Docker : Conteneurisation de l'application
  • Google Gemini : Modèle IA (version gratuite)
  • OpenRouter : Passerelle d'accès aux modèles IA
  • Supervisor : Gestion des processus dans le conteneur

Flux de données

  • L'utilisateur accède à l'interface web via son navigateur
  • Le conteneur Docker héberge Agent Zero, l'API et les services
  • Agent Zero se connecte à Google Gemini via l'API pour les réponses
  • OpenRouter est testé comme alternative mais nécessite des crédits

Test avec OpenRouter - Erreur 402

Premier test de l'assistant avec OpenRouter. Le test échoue avec une erreur 402 Payment Required.

Erreur 402 : crédits insuffisants

⚠️ Difficulté rencontrée

Erreur : "This request requires more credits, or fewer max_tokens. You requested up to 65536 tokens, but can only afford 5000."

Cause : OpenRouter ne propose plus de modèles gratuits. Il faut ajouter des crédits.

✅ Solution

Passage à Google Gemini qui propose une version gratuite avec 20 requêtes par jour.

Erreur 429 - Quota dépassé

Après plusieurs tests, l'erreur 429 Too Many Requests apparaît. Le quota gratuit de 20 requêtes par jour est atteint.

Erreur 429 : quota dépassé

⚠️ Limite atteinte

Message : "Quota exceeded for metric: generativelanguage.googleapis.com/generate_content_free_tier_requests, limit: 20"

Cause : Le compte gratuit Gemini est limité à 20 requêtes par jour.

✅ Solutions possibles

1. Attendre 24h pour la réinitialisation du quota.

2. Ajouter une carte bancaire sur Google Cloud pour augmenter le quota.

3. Utiliser plusieurs comptes Google pour multiplier les requêtes.

4. Passer à un modèle local avec Ollama.

📊 Résultats et apprentissages

Résultats obtenus

  • ✅ Agent Zero est déployé avec succès dans un conteneur Docker Kali Linux
  • ✅ L'interface web est accessible et fonctionnelle
  • ✅ Google Gemini est configuré et répond correctement
  • ✅ OpenRouter est testé mais nécessite des crédits
  • ✅ Compréhension des quotas des versions gratuites (20 requêtes/jour)

Difficultés rencontrées et solutions

Difficulté 1 : OpenRouter payant

Problème : Erreur 402 - crédits insuffisants sur OpenRouter.

Solution : Passage à Google Gemini (version gratuite).

Difficulté 2 : Quota Gemini dépassé

Problème : Erreur 429 - 20 requêtes/jour atteintes.

Solution : Attendre 24h, ajouter une carte bancaire, ou utiliser plusieurs comptes.

✅ Leçon apprise

Les modèles IA gratuits ont des limites (OpenRouter supprime ses modèles gratuits, Gemini limite à 20 requêtes/jour). Pour une utilisation intensive, il est préférable d'utiliser un modèle local avec Ollama ou un compte payant.

🚀 Perspectives d'amélioration

  • Modèles locaux : Installer Ollama et utiliser des modèles 100% gratuits et sans quota (Llama 3, Mistral, Phi, etc.)
  • Déploiement cloud : Héberger Agent Zero sur un serveur VPS avec un domaine personnalisé
  • Intégrations : Connecter l'assistant à des outils de productivité (email, calendrier, etc.)
  • Sécurité : Ajouter une authentification renforcée pour l'interface web
  • Personnalisation : Adapter les prompts pour des cas d'usage spécifiques (réseaux, télécoms, cybersécurité)

🎯 Conclusion

✅ Projet réussi !

Agent Zero a été déployé avec succès dans un conteneur Docker Kali Linux. L'assistant IA autonome fonctionne parfaitement avec Google Gemini, offrant une interface web accessible et une expérience de conversation fluide.

Ce projet a permis de maîtriser Docker, la configuration d'API IA, la gestion des quotas et l'optimisation des paramètres. Il constitue une base solide pour des projets d'IA et d'automatisation plus avancés.
