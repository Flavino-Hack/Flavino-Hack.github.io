VPN Personnel avec OpenVPN & Kali Linux

Conception et déploiement d'une infrastructure VPN auto-hébergée
pour un accès sécurisé à distance

OpenVPN Kali Linux SSL/TLS NAT iptables Easy-RSA
📅 2026 👤 Projet personnel ⏱️ 2 semaines 📶 Auto-hébergé

📌 Contexte & Objectif

Dans le cadre de ma formation en Réseaux Informatiques et Télécommunications, j'ai souhaité mettre en place un VPN personnel pour répondre à plusieurs besoins :

  • Accès sécurisé : Me connecter à mon réseau domestique depuis l'extérieur
  • Confidentialité : Chiffrer mes communications sur les réseaux publics
  • Autonomie : Garder le contrôle total de mon infrastructure
  • Apprentissage : Maîtriser les technologies VPN, PKI, NAT et iptables

L'objectif final était d'obtenir une connexion VPN fonctionnelle depuis un smartphone vers un serveur hébergé sur une machine Kali Linux connectée à une Livebox Orange.

💻 Commandes exécutées

📦 1. Installation d'OpenVPN

# Mise à jour du système
sudo apt update && sudo apt upgrade -y

# Clonage du script d'installation
cd ~
git clone https://github.com/pbxforce/vpn-server-openvpn.git
cd vpn-server-openvpn
sudo bash install-vpn.sh

🔐 2. Génération des certificats

cd /etc/openvpn/easy-rsa
sudo ./easyrsa init-pki
sudo ./easyrsa build-ca nopass
sudo ./easyrsa gen-req server nopass
sudo ./easyrsa sign-req server server
sudo ./easyrsa gen-req client1 nopass
sudo ./easyrsa sign-req client client1
sudo ./easyrsa gen-dh

🌐 3. NAT & IP Forwarding

# Activation IP forwarding
echo "net.ipv4.ip_forward = 1" | sudo tee -a /etc/sysctl.conf
sudo sysctl -p

# Règles iptables
sudo iptables -t nat -A POSTROUTING -s 10.8.0.0/24 -o eth0 -j MASQUERADE
sudo iptables -A FORWARD -i tun0 -j ACCEPT
sudo iptables -A FORWARD -o tun0 -j ACCEPT

📱 4. Création du fichier client .ovpn

cat > monvpn.ovpn << 'EOF'
client
dev tun
proto udp
remote 102.179.234.178 1194
resolv-retry infinite
nobind
persist-key
persist-tun
remote-cert-tls server
cipher AES-256-GCM
verb 3
<ca>
EOF

sudo cat /etc/openvpn/ca.crt >> monvpn.ovpn
echo "</ca>" >> monvpn.ovpn
echo "<cert>" >> monvpn.ovpn
sudo cat /etc/openvpn/client.crt >> monvpn.ovpn
echo "</cert>" >> monvpn.ovpn
echo "<key>" >> monvpn.ovpn
sudo cat /etc/openvpn/client.key >> monvpn.ovpn
echo "</key>" >> monvpn.ovpn

⚡ Défis rencontrés & solutions

💾 Espace disque insuffisant

Disque plein à 100% (19 Go).

✅ Solution

Nettoyage : suppression des logs, caches APT, noyaux anciens.

🔐 Certificats non générés

Le script n'a pas créé la PKI automatiquement.

✅ Solution

Utilisation manuelle d'Easy-RSA.

🔧 IP forwarding désactivé

Le trafic des clients VPN ne passait pas.

✅ Solution

Activation via net.ipv4.ip_forward=1.

🌐 NAT mal configuré

Le trafic des clients VPN ne sortait pas sur Internet.

✅ Solution

Ajout des règles iptables MASQUERADE et FORWARD.

🏠 Port inaccessible de l'extérieur

La Livebox bloquait les connexions entrantes.

✅ Solution

Configuration d'une règle NAT sur la Livebox : port 1194/UDP → 192.168.11.145.
