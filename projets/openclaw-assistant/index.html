Assistant IA Autonome avec OpenClaw

Déploiement d'un agent IA local, accessible via Telegram et WhatsApp
avec un modèle de langage optimisé (phi3:mini) et une infrastructure virtualisée

OpenClawOllama phi3:miniTelegram WhatsAppVMware Ubuntu ServerNode.js
📅 14 août 2026 👤 Projet personnel ⏱️ 3 semaines 📶 Auto-hébergé 🖥️ 24 cœurs CPU

📌 Contexte & Objectif

Dans le cadre de ma formation en Réseaux Informatiques et Télécommunications, j'ai souhaité développer un assistant IA autonome répondant à plusieurs besoins :

  • Autonomie totale : Héberger son propre assistant IA sans dépendre de services cloud payants.
  • Accessibilité multi-canaux : Pouvoir interagir avec l'assistant depuis Telegram et WhatsApp.
  • Confidentialité : Tous les échanges restent sur mon infrastructure, aucune donnée n'est envoyée à des tiers.
  • Apprentissage technique : Maîtriser le déploiement d'agents IA (OpenClaw), la virtualisation (VMware), l'intégration d'APIs et l'optimisation de modèles de langage.

📋 Étapes de Réalisation

1

Création et configuration de la VM

Installation d'Ubuntu Server 24.04 LTS sur VMware avec 6 Go RAM, 24 cœurs CPU et 50 Go de stockage.

🔧 VMware, Ubuntu Server, ISO 24.04
2

Installation de Node.js et OpenClaw

Déploiement de Node.js 22.x et installation globale d'OpenClaw via npm.

🔧 Node.js 22.x, npm, OpenClaw 2026.7.1-2
3

Installation d'Ollama et du modèle phi3:mini

Installation d'Ollama via script officiel, téléchargement du modèle phi3:mini (2.2 Go).

🔧 Ollama, phi3:mini, curl
4

Configuration d'OpenClaw

Paramétrage du Gateway en mode local, configuration du modèle, mise en place du tunnel SSH pour l'accès web.

🔧 openclaw config, openclaw gateway run
5

Intégration de Telegram

Création du bot @flavien_ai_bot avec BotFather, configuration du token et approbation des utilisateurs.

🔧 BotFather, openclaw config channels.telegram
6

Intégration de WhatsApp

Ajout du plugin WhatsApp via ClawHub, scan du QR code, liaison du compte personnel (+22664931693).

🔧 openclaw channels add, WhatsApp Web
7

Optimisation et tests

Tests de performance, optimisation du modèle, mise en place du keep-alive, personnalisation de la langue (français).

🔧 openclaw infer model run, OLLAMA_KEEP_ALIVE

💻 Commandes exécutées

📦 1. Préparation de la VM

# Mise à jour du système sudo apt update && sudo apt upgrade -y # Installation des outils essentiels sudo apt install -y curl git build-essential

🟢 2. Installation de Node.js 22.x

# Ajout du dépôt NodeSource curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash - sudo apt install -y nodejs node --version # v22.23.2

🦞 3. Installation d'OpenClaw

sudo npm install -g openclaw@latest openclaw --version # OpenClaw 2026.7.1-2

📥 4. Installation d'Ollama

curl -fsSL https://ollama.com/install.sh | sh ollama pull phi3:mini OLLAMA_KEEP_ALIVE=10m ollama serve > /dev/null 2>&1 &

⚙️ 5. Configuration d'OpenClaw

openclaw config set models.providers.ollama.api ollama openclaw config set models.providers.ollama.baseUrl "http://localhost:11434" openclaw config set models.providers.ollama.models '[{"id":"phi3:mini","name":"Phi3 Mini"}]' openclaw config set gateway.mode local openclaw gateway run

📱 6. Intégration de Telegram

openclaw config set channels.telegram.botToken "8733023801:AAHulrQqhWPs4TOqwby9jAPIUwPu_3J2Cdo" openclaw config set channels.telegram.enabled true openclaw pairing approve telegram RDP2NSTB

💬 7. Intégration de WhatsApp

openclaw channels add # Sélectionner WhatsApp (QR link), scanner le QR code openclaw config set plugins.allow '["whatsapp"]'

🧪 8. Test de l'assistant

openclaw infer model run --model ollama/phi3:mini --prompt "Bonjour" openclaw logs --follow

⚡ Défis rencontrés & solutions

🔐 Accès au GPU en VM

La RTX 4060 n'était pas accessible directement dans la VM VMware.

✅ Solution

Utilisation d'un modèle léger (phi3:mini) optimisé CPU. Vitesse : 24 tokens/s.

📦 Erreur de permission npm

Impossible d'installer OpenClaw globalement (EACCES).

✅ Solution

Installation avec sudo npm install -g openclaw@latest.

🔑 Authentification du dashboard

Le dashboard refusait la connexion (token_missing).

✅ Solution

Passage en mode gateway.auth.mode none avec tunnel SSH.

🐢 Lenteur de Mistral 7B

Le modèle tournait à 11 tokens/s sur CPU.

✅ Solution

Migration vers phi3:mini (24 tokens/s, 2.5 Go RAM).
