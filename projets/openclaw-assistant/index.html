Assistant IA Autonome avec OpenClaw

Déploiement d'un agent IA local, accessible via Telegram et WhatsApp
avec un modèle de langage optimisé (phi3:mini) et une infrastructure virtualisée

OpenClaw Ollama phi3:mini Telegram WhatsApp VMware Ubuntu Server Node.js
📅 14 août 2026 👤 Projet personnel ⏱️ 3 semaines 📶 Auto-hébergé 🖥️ 24 cœurs CPU

📌 Contexte & Objectif

Dans le cadre de ma formation en Réseaux Informatiques et Télécommunications, j'ai souhaité développer un assistant IA autonome répondant à plusieurs besoins :

  • Autonomie totale : Héberger son propre assistant IA sans dépendre de services cloud payants (OpenAI, Anthropic, etc.).
  • Accessibilité multi-canaux : Pouvoir interagir avec l'assistant depuis Telegram et WhatsApp, les messageries les plus utilisées.
  • Confidentialité : Tous les échanges restent sur mon infrastructure, aucune donnée n'est envoyée à des tiers.
  • Apprentissage technique : Maîtriser le déploiement d'agents IA (OpenClaw), la virtualisation (VMware), l'intégration d'APIs et l'optimisation de modèles de langage.

L'objectif final était d'obtenir un agent IA fonctionnel, capable de comprendre et répondre en français, accessible 24h/24 et 7j/7 via Telegram et WhatsApp, avec un temps de réponse inférieur à 3 secondes.

💻 Commandes exécutées

Voici l'ensemble des commandes utilisées pour la mise en place du projet, organisées par ordre chronologique et commentées.

📦 1. Préparation de la VM

# Mise à jour du système
sudo apt update && sudo apt upgrade -y

# Installation des outils essentiels
sudo apt install -y curl git build-essential

🟢 2. Installation de Node.js 22.x

# Ajout du dépôt NodeSource
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -

# Installation
sudo apt install -y nodejs

# Vérification
node --version  # v22.23.2
npm --version   # 10.9.8

🦞 3. Installation d'OpenClaw

# Installation globale (avec sudo pour éviter les erreurs de permission)
sudo npm install -g openclaw@latest

# Vérification
openclaw --version  # OpenClaw 2026.7.1-2 (0790d9f)

📥 4. Installation d'Ollama et téléchargement du modèle

# Installation d'Ollama
curl -fsSL https://ollama.com/install.sh | sh

# Téléchargement du modèle phi3:mini (2.2 Go)
ollama pull phi3:mini

# Démarrage d'Ollama en arrière-plan avec keep-alive
OLLAMA_KEEP_ALIVE=10m ollama serve > /dev/null 2>&1 &

# Vérification
curl http://localhost:11434  # Ollama is running
ollama list  # phi3:mini présent

⚙️ 5. Configuration d'OpenClaw

# Configuration du modèle
openclaw config set models.providers.ollama.api ollama
openclaw config set models.providers.ollama.baseUrl "http://localhost:11434"
openclaw config set models.providers.ollama.models '[{"id":"phi3:mini","name":"Phi3 Mini"}]'

# Configuration du Gateway (mode local)
openclaw config set gateway.mode local
openclaw config set gateway.bind loopback
openclaw config set gateway.auth.mode none

# Démarrage du Gateway
openclaw gateway run

🔌 6. Tunnel SSH pour l'accès au dashboard

# Depuis Windows (PowerShell)
ssh -N -L 18789:127.0.0.1:18789 flavino@192.168.1.66

# Dashboard accessible sur : http://127.0.0.1:18789/

📱 7. Intégration de Telegram

# Ajout du token du bot
openclaw config set channels.telegram.botToken "8733023801:AAHulrQqhWPs4TOqwby9jAPIUwPu_3J2Cdo"
openclaw config set channels.telegram.enabled true

# Approbation de l'utilisateur
openclaw pairing approve telegram RDP2NSTB

# Vérification
openclaw channels status --channel telegram

💬 8. Intégration de WhatsApp

# Ajout du canal WhatsApp
openclaw channels add
# Sélectionner WhatsApp (QR link)
# Scanner le QR code avec WhatsApp Mobile

# Configurer le mode self-chat
openclaw config set channels.whatsapp.selfChatMode true

# Autoriser le plugin
openclaw config set plugins.allow '["whatsapp"]'

🧪 9. Test de l'assistant

# Test via CLI
openclaw infer model run --model ollama/phi3:mini --prompt "Bonjour"

# Voir les logs en direct
openclaw logs --follow

⚡ Défis rencontrés & solutions

🔐 Accès au GPU en VM

La RTX 4060 de l'hôte n'était pas accessible directement dans la VM VMware.

✅ Solution apportée

Utilisation d'un modèle léger (phi3:mini) optimisé pour le CPU. Vitesse : 24 tokens/s, parfaitement fluide pour une conversation.

📦 Erreur de permission npm

Impossible d'installer OpenClaw globalement (EACCES).

✅ Solution apportée

Installation avec sudo npm install -g openclaw@latest. Le binaire est bien installé dans /usr/lib/node_modules/openclaw.

🔑 Authentification du dashboard

Le dashboard refusait la connexion (token_missing, password_missing).

✅ Solution apportée

Passage en mode gateway.auth.mode none avec gateway.bind loopback et tunnel SSH pour un accès sécurisé en local.

🐢 Lenteur de Mistral 7B

Le modèle mistral:7b tournait à 11 tokens/s sur CPU, rendant la conversation peu fluide.

✅ Solution apportée

Migration vers phi3:mini (3.8B), plus rapide (24 tokens/s) et consommant moins de RAM (2.5 Go).

🔌 Plugin WhatsApp non autorisé

Le plugin WhatsApp se chargeait mais était bloqué (plugins.allow is empty).

✅ Solution apportée

Ajout de "plugins": { "allow": ["whatsapp"] } dans la configuration OpenClaw.
